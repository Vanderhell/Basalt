# Security policy

## Supported versions

Until Basalt reaches a stable release, security fixes target the latest commit on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** function in the repository Security tab to submit a private security advisory.

Include the affected commit/version, provider, operating system, impact, reproduction details, and any suggested mitigation. Do not include real credentials, customer data, or production database contents.

You should receive an acknowledgement within seven days. Findings are investigated and disclosed after a fix or mitigation is available.
